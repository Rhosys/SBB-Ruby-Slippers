# deployment/

This directory contains the signing artifact for Play Store release builds.

## `android-upload-signing.json`

Generated by the `generate-android-keystore` tool from the `_tools` repo:

```bash
generate-android-keystore --alias sbb > deployment/android-upload-signing.json
```

### Expected JSON structure

```json
{
  "keystore": "<base64-encoded PKCS12 keystore (password-protected)>",
  "passwordCiphertext": "<base64-encoded KMS ciphertext of the keystore password>"
}
```

| Field | Description |
|-------|-------------|
| `keystore` | Base64-encoded PKCS12 file. RSA 4096-bit key, 10950-day validity, DN `CN=rhosys.ch, O=Rhosys AG, OU=Mobile, L=Unknown, ST=Unknown, C=CH`. |
| `passwordCiphertext` | Base64-encoded ciphertext produced by AWS KMS (`alias/deployment-encryption-key` in `eu-west-1`). Decrypted at build time via OIDC role assumption. |

### How CI uses this file

1. `build-release` job assumes the GitLab OIDC role (`GitLabRunnerRole`)
2. Extracts `keystore` field → base64 decodes → writes temp `.keystore` file
3. Extracts `passwordCiphertext` → base64 decodes → `aws kms decrypt` → plaintext password
4. Passes both to Gradle via `-Pandroid.injected.signing.*` properties

The plaintext password exists only in memory for the duration of the CI job.
